B0 retains N208 state/reference and includes the explicit safe-primary secondary
degradation code shared by all groups. No failure used to justify changing the
primary QP solver. B1 and B2 share directional uncertainty margins and estimator/
reference changes; only B1 uses lookahead. Report this exact definition.
No new controller is claimed as an original reproduction of any cited work.

Prediction uses one independently built nominal-prior contact model and the
current measured state. Future state is generated by that model, never from a
true trace. The prediction currently has no certified model-error bound or
recursive feasibility proof. No verified candidate terminates the simulation;
zero torque or release is not advertised as a hardware fallback. Recovery is
disabled (zero retries). Estimator rejects duplicate and out-of-order older
observations, processes a batch in stamp order, and rejects future timestamps.
This is not a general out-of-sequence smoother.

Attempts: development<=8, at most two versions; final seen regression<=4;
paired unseen validation<=36; B2<=6; fine<=2; implementation reserve<=4.
Total<=60 including constructor errors and early terminations. Serial process
lock prevents competing ledger writers. CPU and wall limit28800 s, including
prediction, tests and replay. Never extend a task deadline after seeing failure.
Admission to unseen validation requires selected version to pass nominal,H2,S01,
H1 with all actual gates. Otherwise save PARTIAL and do not generate unseen values.
N210/N211 are planning only. No push/merge authorized.

Execution counts come from the N209 run_ledger limits in common.py/benchmark.py.
Inherited N208 mission fields max_development=6 and max_attempts=16 remain in
per-run configuration snapshots as unused legacy metadata; they do not govern
this runner. No archived configuration is rewritten to hide these inherited keys.

## V2 revision registered before its first plant attempt

Only change: the soft instantaneous task-residual admission test applies at
predicted absolute time >=0.20 s. V1 H2 stopped at0.04 s with56.93 mm/s soft
linear residual while its hard constraint set remained feasible. Ten20 ms task
periods are an engineering startup allowance for the bounded acceleration/jerk
and servo ramp, not a derived settling guarantee. Position tracking (8 mm),
geometry, HQP, joint, contact, load, uncertainty and all capture gates continue
from the first tick. The largest residual is still logged, including startup.
No process covariance, physical gate, gain, sensor or terminal horizon changes.
S01 endpoint rejection is unresolved; changing progress has little endpoint
authority. No third version is permitted. V2 will be the final assessed candidate.
