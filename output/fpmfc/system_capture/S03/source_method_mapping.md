# S03 方法来源与边界

本阶段是 Flexiv 工程扩展。源文为梁斌、徐文福、王学谦、闫磊，《自由漂浮空间机器人捕获翻滚目标的力-位-型融合控制方法》，宇航学报 2024，45(6)：958–969，DOI 10.3873/j.issn.1000-1328.2024.06.014。精确文件身份及原文页码沿用 S01/source_contract.json；来源复现缺口沿用 S01/source_ambiguities.md。

|来源定位|原方法要点|S03 对应与差异|
|---|---|---|
|式18–25，PDF 4–11页的 S01 已审读范围|臂形参数与型空间|继续采用已有 Flexiv 肩肘腕几何角；不把 SRS 角度直接搬入 Flexiv|
|式26–27|位型任务层级与末端零空间|保留现有 HQP 末端一级任务、臂形二级任务；末端零空间残差与基座反作用分别记录|
|式28–34|力、位、型融合与接触相关公式|本轮不改力控、接触、锁紧或抓后阻尼；不宣称实现原式完整复现|
|式35，PSO 配置与捕获时间/型角规划|位型协同动机|改为新五维有限确定性候选，增加目标坐标路径偏移；不沿用原文最优时间/角度，也不每20ms运行PSO|

新参数为剩余时间、法向 bump 幅度、固定切向 bump 幅度、臂形中段 bump 幅度、终端臂形相对冻结函数的修正。所有臂形修正都是连续展开的 rad，不是换一套 SRS 定义。位置使用五次端点 jets 加端点二阶导数为零的六次 bump；旋转保留冻结相对 SO(3) 路径，并完整变换物理角速度与角加速度。

以目标几何原点 O 表示实现，固定的 T_OG 与 T_FE 均由现有模型 site 读取。终端满足 T_WF T_FE = T_WO T_OG，等价于 Q_GE(1)=I。平移、旋转运输项由当前 CA18 或原独立整形器给出；预测期间使用独立先验模型，不复制真实目标惯性或未来测量。

完整抓后任务若通过，只构成本项目等效锁紧假设下的扩展。原文的证据范围为接触前。S01 的有假设低扰动基准、PARTIAL 总资格与 C1 缺失原始记录保持；本轮不扩大其结论。
