# 正式规划尝试前的实现修正

首轮 candidate_authority 记录保留。五个变量均产生超过预登记阈值的动作和命名裕量差异，但两项初始状态顺序检查失败。没有据此放行完整机器人尝试。

1. 动力学前瞻错误使用从0.04s起累计的残差峰值做0.2s后的接受门，导致允许的启动峰值在后续低残差时仍被拒绝。修正为冻结原算法所用的“当前任务解残差”，累计峰值继续记录。没有改变阈值或启动截止时间。
2. 顺序检查包含 HQP 的 full_latency_s，重复计算的耗时自然不同。确定性比较只排除 latency_s/full_latency_s 两种墙钟字段；动作、QP数值、命名距离、参考系数、选择与状态均继续核对。

修正后在同一批预登记状态重新执行全部候选检查，原评价仍计入预算。八次逆序复核数值最大误差均为0。18项模块测试和一次21包/零植物积分的首任务 tick 集成检查通过，才冻结 V1。V1之前没有新增 B1/B2 完整尝试；B01 是不受此新预测器缺陷影响的冻结 B0。

入口首次发现 LFS 指针未物化时，原始块校验拒绝读取；随后从本地 LFS 存储物化并通过原有哈希。没有把指针当测量数据，没有修补原始记录。
