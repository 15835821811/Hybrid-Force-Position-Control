# S03 实验计划

主假设：低维时间、相对路径和臂形修正能够在进入不可续行状态之前，改变未来可执行运动及命名约束裕量。支持该假设必须同时有同状态候选权限和从 home 连续执行的任务证据，不能由快照恢复或参数变化代替。

辅助假设：在同等时间/路径搜索资源下，开放臂形自由度有增量收益。只有 B1/B2 同条件完整合格配对才能报告完整时域收益；失败运行保留在任务分母中，仅比较共同前缀。

顺序：B00 归档身份核验与双重放；B01 固定 CA18 理想 H2；预登记有限状态候选权限、数学与隔离测试；D00/D01 一版名义/H2 开发；必要时最多第二版及 D02/D03；冻结后 P00–P03；只有 B2 名义/H2 完整准入后才执行 H1 回归 R00。另留一次可追溯实现错误重试，不用于物理失败后额外调参。

总量以 experiment_manifest.json、run_ledger.json 和 candidate_budget.json 为准：最多12条真实尝试、两版、1000个命名 S03 规划/基线评价、100万完整预测物理步、12小时过程CPU与12小时墙钟。固定抓后制动的原控制行为不作为新增 S03 搜索参数族；其真实计算及预测物理步单列计入总计算。重放不产生新任务成功样本，重复评价和预测物理步另计。

关键指标：真实捕获四门、40ms确认、锁紧后20s及固定末2s；真实载荷、命名距离和执行器余量；基座角速度峰值/RMS与SO(3)漂移；任务时间、参考变化与每次计算耗时。性能残差拒绝和物理越界分开记录。SIM_ABORT 不代表已有安全恢复策略。

理想测量仍通过冻结 CA18 估计器。S02 非理想测量域保持 NOT_ADMITTED，启动/接触协方差问题保留给单独 S02R。不上硬件，不启动 S04–S08，不改变真实模型或守门阈值。
