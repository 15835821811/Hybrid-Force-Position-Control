## 1. 决定

不启动 N072 的十种子随机 PSO，也不对规划不合格候选批量运行 500 Hz 动力学。固定 `ψ_f=π/2` 后只剩捕获时间一个变量；确定性全域筛查和局部 2 ms 细化都显示失败由固定臂形门主导，继续随机搜索不能回答新的科学问题。

这一决定不等于连续时间域数学不可行证明，也不把 N072 标为原 10-seed 协议正式完成。当前状态为 `STOPPED_DIAGNOSTIC`。

## 3. 失败机理

### 3.1 不是“时间不足以完成臂形变化”

初始臂形为约 89.9746°，固定目标为 90°，总期望变化只有约 0.0254°。但 N070 同时间动力学中实际臂形被 6D 末端任务推到约 57.63°--136.74°。因此失败不是大幅臂形过渡来不及完成，而是维持 `π/2` 与当前目标轨迹不相容。

### 3.2 近任务奇异与关节停止裕量竞争唯一零空间方向

N070 fixedpi2 在 `T_c=8 s` 时：

- joint5 在约 5.09 s 到达 `0.039995 rad` 停止裕量，约 30.9% 轨迹低于 0.05 rad；
- joint7 同样到达约 0.04 rad 裕量，约 9.5% 轨迹低于 0.05 rad；
- 广义任务雅可比最大条件数约 155.1，主方法约 33.3；
- 零空间对臂形角的最小敏感度约 0.00178，主方法约 0.0145。

它没有触发 S--E--W 臂形定义的正式奇异：肘平面投影仍大于约 0.0677 m，远高于 `1e-6 m` 阈值。更准确的表述是“近任务奇异 + joint5/joint7 停止约束使唯一零空间方向失去有效臂形调节能力”。

### 3.3 动力学复核再次确认而非造成失败

N070 fixedpi2 的 500 Hz RK4 轨迹在相同 `T_c=8 s` 下失败于终端位置 68.829 mm、臂形 8.193°、线速度 73.544 mm/s 和角速度 0.3009°/s；终端姿态通过。与此同时 400/400 task ticks 的一级/二级 QP 成功，最小间距为 0.302 m，最大动量差为 `4.33e-8`，力矩饱和率为 0，jerk、边界兼容性和确定性重放均通过。

因此 RK4、碰撞、动量与力矩门不是根因。

## 4. 证据边界与后续

当前可支持的结论是：

> 在冻结的 Flexiv 场景和控制器下，固定 `ψ_f=π/2` 在 100 ms 全域筛查及两个关键区域的 2 ms 可执行时间格细化中都未产生规划可行候选；失败由臂形门主导，并与近任务奇异及 joint5/joint7 停止裕量一致。

不得声称连续 `T_c∈[8,25] s` 已被数学证明不可行，也不得把 N072 写成 `0/10 seeds`。若必须给出完整 2 ms 离散域不可行结论，仍需穷举 `8.000+0.002j, j=0,…,8500`。

对论文核心主张更有价值的下一步不是继续 N071/N072，而是冻结一个不读取动态扰动结果的可行固定终端臂形基线，并在完整时间域上作确定性优化。N055R 已暴露负、正两个可行臂形分支；任何由这些结果标定的新基线必须使用新 run ID，明确称为 calibration-derived baseline，并同时报告两个分支，避免事后挑选有利角度。
